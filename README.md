How Does Anthropogenic Noise Pollution Induce Physiological Stress in Hairy Shore Crabs?

By quantifying the effects of anthropogenic noise pollution on the respiration rate of Hemigrapsus in the intertidal, we can start to understand how various stressors via noise pollution affect crab health. As floating concerts increase in popularity, this study can help us understand the effects of events like this on Hemigrapsus.

This is a template repo for generating a manuscript from Quarto that accompanies the tutorial at: [Quarto Manuscripts: RStudio](https://quarto.org/docs/manuscripts/authoring/rstudio.html)
